Online stamp

Create an online stamp image

  1. Open shop.deutschepost.de/internetmarke
  2. Choose a suitable online stamp.
  3. Click the address entry button ("Adresseingabe").
  4. Use the toggle switch to enter addresses or continue without them.
  5. As print format ("Druckformate"), choose "DIN A4 Normalpapier (Einlegeblatt)".
  6. Add it to the cart ("In den Warenkorb") and pay.
  7. Download the online stamp as a .pdf file.

Then attach the PDF with Attach > Stamp. Only the stamp is kept; addresses are removed.

Create an online stamp code

  1. Download and open the Post & DHL app.
  2. Go to code for labeling ("Code zum Beschriften") and follow the instructions.
  3. Detailed guide: deutschepost.de/de/m/mobile-briefmarke.html

Then enter the code in stamp: code (starting with "#").
